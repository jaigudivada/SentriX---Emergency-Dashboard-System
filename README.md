## Overview

SentriX is a real-time emergency response dashboard system that provides live monitoring and quick access to critical emergency resources including hospitals, ambulances, and blood banks. The system features an interactive map, real-time alerts, and one-click emergency contact buttons for police (100), ambulance (108), and fire (101) services.

## Features

- **Real-Time Emergency Dashboard** — Live statistics and status tracking for hospitals, ambulances, and blood banks across the region
- **Interactive Map** — Powered by Leaflet.js with custom markers and popups for emergency resource locations
- **Emergency Contact Buttons** — Quick one-click access to police, ambulance, and fire services
- **Live Alert System** — Real-time alert panel displaying critical, warning, and informational notifications
- **Light/Dark Theme Toggle** — Seamless theme switching for comfortable viewing in any environment
- **Responsive Design** — Fully responsive layout that works across desktops, tablets, and mobile devices
- **Critical Alert Banner** — Prominent system status banner with animated visual indicators

## Technologies Used

- HTML5 & CSS3
- JavaScript (Vanilla)
- Leaflet.js — Interactive mapping
- Font Awesome — Icons
- CSS Custom Properties — Theme management

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/jaigudivada/SentriX---Emergency-Dashboard-System.git
   ```
2. Open `index.html` in your browser.

No build tools or server setup required — simply open the file and the dashboard is ready.

## Usage

- **Dashboard Overview** — View real-time statistics for emergency resources
- **Map Interaction** — Pan and zoom to explore resource locations; click markers for details
- **Theme Toggle** — Switch between light and dark mode using the theme selector in the header
- **Emergency Contacts** — Click any emergency button to dial the respective service
- **Resource Lists** — Browse available hospitals, ambulances, and blood banks in the sidebar
- **Alert Monitoring** — Keep track of critical system alerts and notifications
